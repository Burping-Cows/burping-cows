# DM Sans

These local font instances use optical size **14**, matching the `opsz` setting returned by the supplied Figma design. The regular, medium and bold instances have weights 400, 500 and 700. They are loaded under the app's existing font-family names.

Source: [Google Fonts DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans), downloaded 3 October 2026. Instances were generated from `DMSans[opsz,wght].ttf` with FontTools. The SIL Open Font License is included in `OFL.txt`.
